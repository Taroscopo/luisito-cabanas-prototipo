# Instrucciones de implementación incorporadas al prototipo

## Objetivo
Construir la primera versión visual y funcional de la web de Luisito el Viajero, orientada a promocionar cabañas, pasadías y espacios para eventos en el Atlántico, Colombia.

## Reglas de ejecución
1. No solicitar precios, capacidades, fotografías reales, logotipos ni datos de propietarios. Usar información ficticia coherente para demostrar el resultado.
2. Implementar una web real mediante código. No convertir una captura de pantalla, un diseño exportado ni una imagen generada en la página web.
3. Usar HTML5, CSS y JavaScript modular, sin introducir React o Next.js innecesariamente.
4. Mantener una experiencia premium, cinematográfica, editorial y minimalista.
5. No implementar pagos, reservas confirmadas ni consulta automática de disponibilidad.
6. Centralizar las propiedades y sus tarifas ficticias en una estructura de datos fácil de editar.

## Funcionalidades incluidas
- Hero visual con espacio reservado para material auténtico de Luisito.
- Catálogo de tres propiedades ficticias.
- Ficha de propiedad con visualización demostrativa de reel, galería, amenidades, ubicación y tarifas.
- Calculadora por rangos de ocupación, noches o pasadía, con anticipo ilustrativo.
- Formulario que prepara un resumen para WhatsApp y valida los datos básicos.
- Número comercial vacío a propósito; no se envía información a teléfonos inventados.
- Responsive, menú móvil, modales accesibles, movimiento reducido y estados de error.
- Sin backend, pagos ni confirmación automática.

## Criterio de aceptación
La entrega debe ser un proyecto ejecutable y no solo el hero ni un conjunto de tarjetas. Deben probarse las interacciones disponibles, las validaciones, la aritmética, los casos fuera de capacidad y el comportamiento móvil. Los datos de ejemplo deben quedar centralizados y ser fáciles de sustituir.
